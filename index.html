Biography

I am a Ph.D. candidate (2024.9 - 2029.6) in the WebSoft Research Group at the School of Computer Science, Nanjing University, advised by Prof. Wei Hu. My research focuses on modern database systems, especially high-dimensional vector querying and multimodal data retrieval in vector database.

Before my Ph.D. career, I received my B.S. degree in Computer Science from Nanjing University in 2024.

Projects

NJUDB: A relational database for undergraduate students

Covers storage, indexing, query processing and optimization, transaction management and concurrency control. The project is designed to provide a comprehensive learning experience in database systems for undergraduate students.

Project Page Code Repository

WoWLib: Fast index for range filtering vector search

Fast index for range filtering vector search, with incremental update and efficient query processing for varying selectivities. Header-only C++ library, with Python bindings and SIMD support.
